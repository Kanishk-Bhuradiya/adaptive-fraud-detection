## Dataset (not bundled)
IEEE-CIS Fraud Detection (Vesta Corporation), public on Kaggle:
https://www.kaggle.com/competitions/ieee-fraud-detection/data
Files used: `train_transaction.csv`, `train_identity.csv`. A free Kaggle account and acceptance of the competition rules are required
(CLI: `kaggle competitions download -c ieee-fraud-detection`). The competition terms do not allow redistribution, so the data are not included.

## How to reproduce
1. On Kaggle, create a notebook, add the competition data, and (optionally) add `bundle.joblib` as a private dataset.
2. In `fraud-drift-clean.ipynb`, Part 0, set `DATA_DIR` and `BUNDLE` paths. `TRAIN_FROM_SCRATCH = False` loads the saved models (about 15-25 min);
   `True` retrains everything (about 1 h). `RUN_EXTRA_EXPERIMENTS = True` adds the random-split model and the 5-seed noise test.
3. Run Parts 0-3 first; every `stepNN` file is pasted as an extra cell after them (they list the variables they need in their header comments).
   `step30_31` is self-contained and replaces `df`, so run it last or in its own session.
Runtimes quoted in the notebook are estimates; the logistic-regression variants (step 32) took about 68 minutes on the real data.
